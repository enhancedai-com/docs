## O que isso habilita

Uma vez conectado, você pode perguntar ao Claude coisas como:

- *"Quais agentes tenho no FluxPrompt?"*
- *"Mostre a estrutura do meu agente Lead Scorer"*
- *"Quais tipos de node estão disponíveis no FluxPrompt?"*

O Claude chamará as tools do FluxPrompt MCP automaticamente e exibirá os resultados inline.

<Note>
**OAuth é a forma recomendada de conectar, em todos os ambientes.** O Claude Desktop adiciona o FluxPrompt como um **conector** por uma **URL HTTPS** e faz seu login com OAuth: você entra por uma tela de consentimento do FluxPrompt e nunca manipula um token. Veja [Autenticação](/mcp/pt-br/authentication).
</Note>

<Warning>
Conectores são adicionados no aplicativo, não em um arquivo de configuração. Não adicione uma `url` do FluxPrompt nem um header `Authorization` ao `claude_desktop_config.json`; esse arquivo não é a forma de o Claude Desktop se conectar a um servidor remoto.
</Warning>

## Pré-requisitos

- Claude Desktop instalado ([baixar aqui](https://claude.ai/download))
- Uma conta FluxPrompt com acesso a pelo menos um workspace

## Passo a passo

<Steps>
  <Step title="Abra as configurações de conectores">
    No Claude Desktop, vá em **Customize → Connectors** e clique em **Add custom connector**.
  </Step>
  <Step title="Informe a URL do servidor FluxPrompt">
    Cole a URL HTTPS do servidor FluxPrompt MCP:

    ```
    https://mcp.fluxprompt.ai/mcp
    ```

    Dê ao conector um nome reconhecível (ex.: `FluxPrompt`). Em autenticação, escolha **Sign in**: **Use Claude's published identity** (recomendado) ou **Register automatically**. Ambos funcionam com o FluxPrompt. Depois confirme.
  </Step>
  <Step title="Faça login e conceda acesso">
    O Claude abre uma tela de login + consentimento do FluxPrompt. Faça login com sua conta FluxPrompt. A tela de consentimento lista suas **Organizations** — todas vêm marcadas, então desmarque as que você não quer liberar — e clique em **Authorize**.

    Nenhum token está envolvido — a autenticação é feita inteiramente por esse fluxo OAuth.
  </Step>
  <Step title="Verifique a conexão">
    Em uma nova conversa, digite:

    > *Liste meus agentes FluxPrompt*

    O Claude deve responder com a lista de agentes do seu workspace. Se aparecer um erro, consulte a página de [Solução de problemas](/mcp/pt-br/troubleshooting).
  </Step>
</Steps>

## Usar um servidor local

O Claude Desktop chama o conector a partir do backend da Anthropic, não da sua máquina, então `http://localhost:3100/mcp` é inacessível. Para testar um `mcp-server` local, exponha-o por um túnel HTTPS público (cloudflared ou ngrok) e adicione `https://<seu-túnel>/mcp` como URL do conector. Veja [Túneis](/mcp/pt-br/connect/local-dev#túneis) e [Testar com o Claude Desktop](/mcp/pt-br/connect/local-dev#passo-3-testar-com-o-claude-desktop-via-túnel). Para um cliente de terminal que alcança o `localhost` diretamente, use o [Claude Code](/mcp/pt-br/connect/claude-code).

## O que o Claude pode fazer com o FluxPrompt

Após a conexão, o Claude pode chamar o catálogo de tools do FluxPrompt. Quais tools ele consegue usar depende dos escopos da sua autorização; veja [Escopos](/mcp/pt-br/authentication#escopos) e [O que uma autorização OAuth inclui](/mcp/pt-br/authentication#o-que-uma-autorização-oauth-inclui) para saber por quanto tempo ela dura.

O Claude escolherá a tool correta automaticamente com base na sua pergunta. Você também pode pedir explicitamente: *"Use `get_agent` para mostrar a estrutura do agente de ID abc123"*.

## Solução de problemas

Se a conexão não estiver funcionando, consulte a página de [Solução de problemas](/mcp/pt-br/troubleshooting). Os problemas mais comuns são:

- Tentar usar um token colado ou uma entrada em arquivo de configuração em vez do fluxo **Sign in** (OAuth)
- Adicionar uma URL `localhost`: o Claude Desktop não a alcança, use um túnel
- Não concluir a tela de login + consentimento do FluxPrompt
- Deixar as organizações erradas marcadas durante o consentimento
