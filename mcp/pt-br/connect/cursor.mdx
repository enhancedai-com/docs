## O que isso habilita

Uma vez conectado, o assistente de IA do Cursor pode responder perguntas sobre seus agentes FluxPrompt sem sair do editor:

- *"Quais agentes tenho configurados para enriquecimento de leads?"*
- *"Mostre os nodes do agente Email Parser para eu replicar a lógica aqui"*

## Pré-requisitos

- Cursor instalado ([baixar aqui](https://cursor.sh))
- Um **service token** de workspace do FluxPrompt (veja [Autenticação](/mcp/pt-br/authentication)) — gere um em [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens)

<Note>
O Cursor também pode autenticar via **OAuth** (adicione a URL do servidor e conclua o fluxo de login + consentimento do FluxPrompt), igual ao Claude Code. Este guia usa um service token estático, útil para setups compartilhados ou headless. Qualquer um dos métodos funciona.
</Note>

## Passo a passo

<Steps>
  <Step title="Abra as configurações do Cursor">
    Pressione `Cmd/Ctrl + Shift + P` para abrir a paleta de comandos, digite `MCP` e selecione **Cursor Settings → MCP**.

    Alternativamente, vá em **Settings → Features → MCP Servers**.
  </Step>
  <Step title="Adicione um novo servidor MCP">
    Clique em **Add new MCP server** e preencha os campos:

    | Campo | Valor |
    |-------|-------|
    | **Name** | `fluxprompt` |
    | **Type** | `url` |
    | **URL** | `https://mcp.fluxprompt.ai/mcp` |

    Para o header **Authorization**, adicione:
    ```
    Authorization: Bearer YOUR_SERVICE_TOKEN
    ```

    Substitua `YOUR_SERVICE_TOKEN` pelo seu service token real (começa com `mcp_`).
  </Step>
  <Step title="Salve e verifique">
    Salve as configurações. O Cursor se conecta imediatamente — nenhum reinício é necessário.

    Abra o chat de IA (`Cmd/Ctrl + L`) e digite:

    > *Liste meus agentes FluxPrompt*

    Você deverá ver seus agentes do workspace listados.
  </Step>
</Steps>

## Tools e escopos

O Cursor pode chamar todo o catálogo de tools do FluxPrompt. Quais ele consegue usar depende dos escopos da sua chave:

| Escopo | O que libera | Catálogo |
|--------|--------------|----------|
| `read` | Listar e inspecionar agentes, pastas, versões, tipos de node, modelos, integrações e vozes | [Agentes e pastas](/mcp/pt-br/tools/agents-and-folders), [Nodes e edges](/mcp/pt-br/tools/nodes-and-edges), [Versionamento](/mcp/pt-br/tools/versioning) |
| `write` | Criar e editar agentes, pastas, nodes e edges; criar snapshots e publicar versões | [Escrevendo com segurança](/mcp/pt-br/tools/writing-safely), [Agentes e pastas](/mcp/pt-br/tools/agents-and-folders), [Nodes e edges](/mcp/pt-br/tools/nodes-and-edges), [Versionamento](/mcp/pt-br/tools/versioning) |
| `execute` | Executar um agente, acompanhar uma execução, cancelar uma execução | [Executando agentes](/mcp/pt-br/tools/running-agents) |

Uma tool que a sua autorização não cobre é recusada com `-32401 Insufficient scope`. As tools de escrita e execução também exigem que as configurações correspondentes do workspace estejam ligadas — veja [Autenticação](/mcp/pt-br/authentication#interruptores-no-nível-do-workspace).

## Configuração manual (JSON)

Se preferir editar o arquivo de configuração diretamente, o arquivo MCP do Cursor fica em:

```
~/.cursor/mcp.json            (macOS / Linux)
%USERPROFILE%\.cursor\mcp.json  (Windows)
```

Adicione a entrada do FluxPrompt:

```json
{
  "mcpServers": {
    "fluxprompt": {
      "url": "https://mcp.fluxprompt.ai/mcp",
      "headers": {
        "Authorization": "Bearer mcp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
      }
    }
  }
}
```
