## Descrição

`list_node_types` retorna o catálogo de todos os tipos de node disponíveis no FluxPrompt — o que cada um faz, quais entradas aceita e quais saídas produz. Use isso para entender os blocos de construção dos quais um agente é composto.

## Entrada

Nenhum parâmetro necessário.

## Saída

```json
{
  "nodeTypes": [
    {
      "type": "commandTextNode",
      "label": "Command Text Node",
      "description": "Runs a prompt against an AI text model and passes the result downstream.",
      "category": "AI",
      "inputSchema": {
        "type": "object",
        "properties": {
          "prompt": { "type": "string", "description": "The prompt to run" },
          "aiModel": { "type": "string", "description": "AI model name, e.g. \"gemini-2.5-flash-lite\"" },
          "aiSystem": { "type": "string", "description": "AI provider, e.g. \"gemini\", \"anthropic\", \"openAi\"" }
        },
        "required": ["prompt", "aiModel", "aiSystem"]
      },
      "outputSchema": {
        "type": "object",
        "properties": {
          "text": { "type": "string", "description": "Generated text output" }
        }
      }
    },
    {
      "type": "conditionNode",
      "label": "Condition Node",
      "description": "Evaluates a condition and routes flow execution along the true or false branch.",
      "category": "Logic",
      "inputSchema": { "..." : "..." },
      "outputSchema": { "..." : "..." }
    }
  ]
}
```

### Campos da saída

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `nodeTypes` | array | Lista completa de tipos de node. |
| `nodeTypes[].type` | string | Identificador legível por máquina (camelCase, ex.: `commandTextNode`). Corresponde ao campo `type` nos objetos de node do `get_agent`. |
| `nodeTypes[].label` | string | Nome legível por humanos conforme exibido no canvas do FluxPrompt. |
| `nodeTypes[].description` | string | O que este node faz. |
| `nodeTypes[].category` | string | Agrupamento: `Input/Output`, `AI`, `Data`, `Logic`, `Utility`, `Integration`. |
| `nodeTypes[].inputSchema` | JSON Schema | A configuração que este node aceita. |
| `nodeTypes[].outputSchema` | JSON Schema | Os dados que este node produz para nodes downstream. |

<Warning>
  **Respeite o `enum` quando o campo declarar um.** Vários campos de node aceitam apenas um
  conjunto fixo de valores — por exemplo, `dynamicSettingsNode.selectedOption` é `"text"` ou
  `"voice"`, e `fluxObject.selectedType` é uma de seis strings exatas, como `"Load All Entries"`.
  Esses campos **não** são validados na escrita: um valor fora da lista é gravado sem erro e depois
  não casa com nenhum branch na renderização, então o node fica sem painel selecionado e não faz
  nada. Sempre leia o `enum` do campo no `inputSchema` antes de escrevê-lo, e nunca chute um valor
  que pareça plausível, como `"default"`.
</Warning>

## Exemplos de prompts

- *"Quais tipos de node o FluxPrompt suporta?"*
- *"Liste todos os tipos de node de IA no FluxPrompt"*
- *"Quais entradas o node Command Text Node aceita?"*
- *"Existem tipos de node para consultas de banco de dados no FluxPrompt?"*
