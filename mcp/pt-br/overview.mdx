## O que é o FluxPrompt MCP?

**FluxPrompt MCP** é um servidor [Model Context Protocol](https://modelcontextprotocol.io) de entrada. Ele permite que clientes de IA externos — Claude Desktop, Codex, OpenCode, Cursor, n8n e outros — se conectem ao seu workspace FluxPrompt e interajam com seus agentes por linguagem natural.

Em vez de navegar pela interface do FluxPrompt, seu cliente de IA pode fazer perguntas como:

- *"Liste todos os agentes do meu workspace"*
- *"Mostre os nodes dentro do agente Invoice Parser"*
- *"Quais tipos de node o FluxPrompt suporta?"*

## Autenticação em resumo

O FluxPrompt MCP suporta **dois** métodos de autenticação, e o correto depende do seu cliente:

- **OAuth 2.0** — você adiciona a URL do servidor como conector, faz login por uma tela de consentimento do FluxPrompt e escolhe um ou mais workspaces. Nenhum token é colado. É **obrigatório** para Claude Desktop e Claude.ai (que rejeitam tokens colados) e também é suportado por Claude Code / CLI, Codex e Cursor.
- **Service token estático** — qualquer membro ativo de um workspace gera uma chave (começa com `mcp_`) em [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens) e a coloca no header `Authorization`. É para clientes máquina-a-máquina, a CLI, o Codex, o OpenCode, o Cursor e o n8n — clientes que não podem ou não devem executar um fluxo de consentimento no navegador.

| Cliente | OAuth | Service token estático |
|---------|-------|------------------------|
| Claude Desktop | ✅ obrigatório | ❌ não suportado |
| Claude.ai | ✅ obrigatório | ❌ não suportado |
| Claude Code / CLI | ✅ | ✅ |
| Codex CLI | ✅ | ✅ |
| OpenCode | limitado | ✅ recomendado |
| Cursor | ✅ | ✅ |
| n8n | parcial | ✅ recomendado |
| Serviços de backend (M2M) | ❌ (sem navegador) | ✅ |

Veja [Autenticação](/mcp/pt-br/authentication) para todos os detalhes.

<Note>
  Ferramentas de escrita e execução exigem uma chave com os escopos `write`/`execute` **e** as
  configurações correspondentes do workspace: **Let AI assistants change things** (`mcp.writes.enabled`)
  e **Let AI assistants run agents** (`mcp.execute.enabled`). Ambas vêm ligadas por padrão, e um admin do
  workspace as controla em **Settings → MCP Keys**.
</Note>

### Limites

- **Cota de execuções** — cada workspace pode iniciar até **200** execuções de agentes por dia (UTC) via MCP. Depois disso, o `run_agent` é recusado com `quota_exceeded` até o próximo dia UTC. Um dry-run não consome a cota; ele informa `quotaRemaining`.
- **Limite de requisições** — cada chave pode fazer 60 requisições por minuto e 5.000 por dia por padrão.

## Como funciona

```
Seu cliente de IA (Claude Desktop / Cursor / n8n)
        │
        │  JSON-RPC sobre HTTPS
        │  Sessão OAuth  ou  Authorization: Bearer <service token>
        ▼
Servidor FluxPrompt MCP  (mcp.fluxprompt.ai)
        │
        │  lê seu workspace
        ▼
FluxPrompt API  ──▶  Seus agentes, nodes e flows
```

1. Você se autentica via **OAuth** (consentimento no navegador) ou um **service token**, dependendo do seu cliente.
2. Seu cliente de IA se conecta a `https://mcp.fluxprompt.ai/mcp`.
3. Ele chama as ferramentas — por exemplo `list_agents`, `get_agent`, `list_node_types` — e recebe respostas estruturadas. Veja as páginas de ferramentas acima para o catálogo completo.
4. Cada chamada é registrada no log de auditoria do FluxPrompt.

### Transporte

- Toda requisição é um `POST` HTTP para `/mcp` com uma mensagem JSON-RPC 2.0. A resposta é JSON simples.
- Se o seu cliente enviar `Accept: text/event-stream`, a resposta é um único frame SSE (um evento `data:` e o stream fecha em seguida). Não há stream de servidor de longa duração, então `GET /mcp` não é suportado.
- Uma notificação JSON-RPC (mensagem sem `id`) é respondida apenas com `202 Accepted`.
- `DELETE /mcp` encerra uma sessão e retorna `204`. Nada é guardado no servidor, então é seguro ignorar.

## Glossário rápido

| Termo | Significado |
|-------|-------------|
| **MCP** | Model Context Protocol — um padrão aberto para conectar clientes de IA a ferramentas e dados externos. |
| **OAuth** | Um fluxo de consentimento no navegador em que você faz login no FluxPrompt e concede a um cliente acesso a um workspace. Nenhum token é colado. Obrigatório para Claude Desktop e Claude.ai. |
| **Service token** | Uma string secreta vinculada ao seu workspace (e, opcionalmente, a outros workspaces de que você faz parte) (começa com `mcp_`), gerada em [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens). Enviada no header `Authorization`. Usada por clientes máquina-a-máquina, a CLI e o n8n. Diferente da sua API key do FluxPrompt. |
| **Tool** | Uma ação nomeada que o servidor MCP expõe (ex.: `list_agents`). Seu cliente de IA chama as tools em seu nome. |
| **Workspace** | O contexto da sua empresa ou equipe no FluxPrompt. Uma autorização (OAuth ou service token) pode cobrir um workspace ou vários — veja [Autenticação](/mcp/pt-br/authentication#uma-autorização-pode-cobrir-vários-workspaces). |
| **Streamable HTTP** | O protocolo de transporte que o FluxPrompt MCP utiliza. Um único endpoint HTTPS que aceita requisições JSON-RPC 2.0. |

## Antes de começar

Você vai precisar de:

- Uma **conta FluxPrompt** com pelo menos um agente no seu workspace.
- Um cliente compatível com OAuth (Claude Desktop, Claude.ai, Claude Code, Codex, Cursor) ou um **service token** de [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens) para clientes baseados em token (OpenCode, n8n, serviços de backend).
- Um dos clientes de IA suportados instalado.

<Note>
Este guia assume que o servidor FluxPrompt MCP está em `https://mcp.fluxprompt.ai/mcp`. Se a sua equipe usa um endpoint dedicado, utilize esse no lugar.
</Note>
