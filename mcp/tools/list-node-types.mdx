## Description

`list_node_types` returns the catalogue of every node type available in FluxPrompt — what each one does, what inputs it accepts, and what outputs it produces. Use this to understand the building blocks an agent is made of.

## Input

No parameters required.

## Output

```json
{
  "nodeTypes": [
    {
      "type": "commandTextNode",
      "label": "Command Text Node",
      "description": "Runs a prompt against an AI text model and passes the result downstream.",
      "category": "AI",
      "inputSchema": {
        "type": "object",
        "properties": {
          "prompt": { "type": "string", "description": "The prompt to run" },
          "aiModel": { "type": "string", "description": "AI model name, e.g. \"gemini-2.5-flash-lite\"" },
          "aiSystem": { "type": "string", "description": "AI provider, e.g. \"gemini\", \"anthropic\", \"openAi\"" }
        },
        "required": ["prompt", "aiModel", "aiSystem"]
      },
      "outputSchema": {
        "type": "object",
        "properties": {
          "text": { "type": "string", "description": "Generated text output" }
        }
      }
    },
    {
      "type": "conditionNode",
      "label": "Condition Node",
      "description": "Evaluates a condition and routes flow execution along the true or false branch.",
      "category": "Logic",
      "inputSchema": { "..." : "..." },
      "outputSchema": { "..." : "..." }
    }
  ]
}
```

### Output fields

| Field | Type | Description |
|-------|------|-------------|
| `nodeTypes` | array | Full list of node types. |
| `nodeTypes[].type` | string | Machine-readable identifier (camelCase, e.g. `commandTextNode`). Matches the `type` field in `get_agent` node objects. |
| `nodeTypes[].label` | string | Human-readable name as shown in the FluxPrompt canvas. |
| `nodeTypes[].description` | string | What this node does. |
| `nodeTypes[].category` | string | Grouping: `Input/Output`, `AI`, `Data`, `Logic`, `Utility`, `Integration`. |
| `nodeTypes[].inputSchema` | JSON Schema | The configuration this node accepts. |
| `nodeTypes[].outputSchema` | JSON Schema | The data this node produces for downstream nodes. |

<Warning>
  **Respect `enum` when a field declares one.** Several node fields only accept a fixed set of
  values — for example `dynamicSettingsNode.selectedOption` is `"text"` or `"voice"`, and
  `fluxObject.selectedType` is one of six exact strings such as `"Load All Entries"`. These fields
  are **not** validated on write: a value outside the list is stored happily and then matches no
  branch at render time, so the node ends up with no panel selected and does nothing. Always read
  the field's `enum` from `inputSchema` before writing it, and never guess a plausible-looking
  value like `"default"`.
</Warning>
