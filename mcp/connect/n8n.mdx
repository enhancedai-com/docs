## What this enables

Inside n8n you can build workflows that automatically:

- Fetch the list of your FluxPrompt agents
- Inspect an agent's node structure
- Branch logic based on what agents exist

## Prerequisites

- n8n instance (cloud or self-hosted, v1.22+)
- A FluxPrompt workspace **service token** — generate one under [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens); see [Generate a service token](/mcp/authentication#generate-a-service-token). A static service token is the recommended method for n8n. The key's scopes decide which tools n8n can call; see [Scopes](/mcp/authentication#scopes).

## Step-by-step

<Steps>
  <Step title="Add an MCP Client Tool node">
    In your n8n workflow, click **+** to add a node. Search for **MCP Client Tool** and select it.
  </Step>
  <Step title="Configure the connection">
    In the node settings, set:

    | Field | Value |
    |-------|-------|
    | **Server URL** | `https://mcp.fluxprompt.ai/mcp` |
    | **Authentication** | Header Auth |
    | **Header Name** | `Authorization` |
    | **Header Value** | `Bearer YOUR_SERVICE_TOKEN` |

    Replace `YOUR_SERVICE_TOKEN` with your actual service token (starts with `mcp_`).
  </Step>
  <Step title="Choose the tool and parameters">
    In the **Tool** dropdown, select the FluxPrompt tool you want, for example:

    - `list_agents` — no parameters required; optional `search`, `folderId`, `folderName` and `cursor`
    - `get_agent` — requires `agentId` (the agent's UUID)
    - `list_node_types` — no parameters required

    Set any required parameters in the **Tool Parameters** section. The full list of tools and their parameters is in the [tool catalog](/mcp/tools/agents-and-folders).
  </Step>
  <Step title="Test the node">
    Click **Execute node**. The output will contain the structured response from FluxPrompt.
  </Step>
</Steps>

## Example: find agents by name

This workflow finds the FluxPrompt agents whose name contains "Parser":

1. **MCP Client Tool** — calls `list_agents` with `search` set to `Parser`. The server filters by name (case-insensitive), so you don't need a Code node for a simple match.
2. **Pagination (only when needed)** — `list_agents` returns a page of up to 50 agents as `{ agents, total, nextCursor }`. If `nextCursor` is present, call the tool again with `cursor` set to it and the **same** `search`, `folderId` and `folderName`; a cursor is bound to the filters that produced it and is rejected if you change them. If `nextCursor` is absent, that page is everything.
3. **Code node** — if you paged, combine the pages, for example `return $input.all().flatMap(item => item.json.agents)`.
4. **Whatever you need next** — send results to Slack, write to a spreadsheet, etc.
