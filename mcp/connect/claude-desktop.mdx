## What this enables

Once connected, you can ask Claude things like:

- *"What agents do I have in FluxPrompt?"*
- *"Show me the structure of my Lead Scorer agent"*
- *"What node types are available in FluxPrompt?"*

Claude will call the FluxPrompt MCP tools automatically and show you the results inline.

<Note>
**OAuth is the recommended way to connect, in every environment.** Claude Desktop adds FluxPrompt as a **connector** by an **HTTPS URL** and signs you in with OAuth: you log in through a FluxPrompt consent screen and never handle a token. See [Authentication](/mcp/authentication).
</Note>

<Warning>
Connectors are added in the app, not in a config file. Do not add a FluxPrompt `url` or an `Authorization` header to `claude_desktop_config.json`; that file is not how Claude Desktop connects to a remote server.
</Warning>

## Prerequisites

- Claude Desktop installed ([download here](https://claude.ai/download))
- A FluxPrompt account with access to at least one workspace

## Step-by-step

<Steps>
  <Step title="Open the connector settings">
    In Claude Desktop, go to **Customize → Connectors** and click **Add custom connector**.
  </Step>
  <Step title="Enter the FluxPrompt server URL">
    Paste the FluxPrompt MCP server HTTPS URL:

    ```
    https://mcp.fluxprompt.ai/mcp
    ```

    Give the connector a recognizable name (e.g. `FluxPrompt`). Under authentication, choose **Sign in**: either **Use Claude's published identity** (recommended) or **Register automatically**. Both work with FluxPrompt. Then confirm.
  </Step>
  <Step title="Log in and grant access">
    Claude opens a FluxPrompt login + consent screen. Log in with your FluxPrompt account. The consent screen lists your **Organizations** — all are checked, so uncheck any you don't want to grant — then click **Authorize**.

    No token is involved — authentication is handled entirely through this OAuth flow.
  </Step>
  <Step title="Verify the connection">
    In a new conversation, type:

    > *List my FluxPrompt agents*

    Claude should respond with a list of agents from your workspace. If you see an error, check the [Troubleshooting](/mcp/troubleshooting) page.
  </Step>
</Steps>

## Use a local server

Claude Desktop calls the connector from Anthropic's backend, not from your machine, so `http://localhost:3100/mcp` is unreachable. To test a local `mcp-server`, expose it through a public HTTPS tunnel (cloudflared or ngrok) and add `https://<your-tunnel>/mcp` as the connector URL. See [Tunnels](/mcp/connect/local-dev#tunnels) and [Test with Claude Desktop](/mcp/connect/local-dev#step-3-test-with-claude-desktop-via-a-tunnel). For a terminal client that reaches `localhost` directly, use [Claude Code](/mcp/connect/claude-code).

## What Claude can do with FluxPrompt

After connecting, Claude can call the FluxPrompt tool catalog. Which tools it can use depends on the scopes of your authorization; see [Scopes](/mcp/authentication#scopes), and [What an OAuth grant includes](/mcp/authentication#what-an-oauth-grant-includes) for how long it lasts.

Claude will choose the right tool automatically based on your question. You can also ask it explicitly: *"Use `get_agent` to show me the structure of agent ID abc123"*.

## Troubleshooting

If the connection isn't working, see the [Troubleshooting](/mcp/troubleshooting) page. The most common issues are:

- Trying to use a pasted token or a config-file entry instead of the **Sign in** (OAuth) flow
- Adding a `localhost` URL: Claude Desktop cannot reach it, use a tunnel
- Not completing the FluxPrompt login + consent screen
- Leaving the wrong organizations checked during consent
