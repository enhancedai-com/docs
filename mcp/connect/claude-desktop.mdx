## What this enables

Once connected, you can ask Claude things like:

- *"What agents do I have in FluxPrompt?"*
- *"Show me the structure of my Lead Scorer agent"*
- *"What node types are available in FluxPrompt?"*

Claude will call the FluxPrompt MCP tools automatically and show you the results inline.

<Warning>
**Claude Desktop does not accept pasted tokens.** It rejects user-supplied bearer tokens, so FluxPrompt connects via **OAuth** instead — you log in through a FluxPrompt consent screen and never handle a token. Do not try to add an `Authorization` header in a config file; it will not work. See [Authentication](/mcp/authentication).
</Warning>

## Prerequisites

- Claude Desktop installed ([download here](https://claude.ai/download))
- A FluxPrompt account with access to at least one workspace

## Step-by-step

<Steps>
  <Step title="Open the connector settings">
    In Claude Desktop, go to **Settings → Connectors** and click **Add custom connector**.
  </Step>
  <Step title="Enter the FluxPrompt server URL">
    Paste the FluxPrompt MCP server URL:

    ```
    https://mcp.fluxprompt.ai/mcp
    ```

    Give the connector a recognizable name (e.g. `FluxPrompt`) and confirm.
  </Step>
  <Step title="Log in and grant access">
    Claude opens a FluxPrompt login + consent screen. Log in with your FluxPrompt account. The consent screen lists your **Organizations** — all are checked, so uncheck any you don't want to grant — then click **Authorize**.

    No token is involved — authentication is handled entirely through this OAuth flow.
  </Step>
  <Step title="Verify the connection">
    In a new conversation, type:

    > *List my FluxPrompt agents*

    Claude should respond with a list of agents from your workspace. If you see an error, check the [Troubleshooting](/mcp/troubleshooting) page.
  </Step>
</Steps>

## What Claude can do with FluxPrompt

After connecting, Claude can call the FluxPrompt tool catalog. Which tools it can actually use depends on the scopes granted when you authorized:

| Scope | What it unlocks | Catalog |
|-------|-----------------|---------|
| `read` | List and inspect agents, folders, versions, node types, models, integrations and voices | [Agents & folders](/mcp/tools/agents-and-folders), [Nodes & edges](/mcp/tools/nodes-and-edges), [Versioning](/mcp/tools/versioning) |
| `write` | Create and edit agents, folders, nodes and edges; snapshot and publish versions | [Writing safely](/mcp/tools/writing-safely), [Agents & folders](/mcp/tools/agents-and-folders), [Nodes & edges](/mcp/tools/nodes-and-edges), [Versioning](/mcp/tools/versioning) |
| `execute` | Run an agent, poll a run, cancel a run | [Running agents](/mcp/tools/running-agents) |

A tool your authorization does not cover is refused with `-32401 Insufficient scope`. Write and execute tools also need the matching workspace settings turned on — see [Authentication](/mcp/authentication#workspace-level-switches).

### Which scopes you granted

You do not pick scopes on the consent screen: FluxPrompt grants the scopes the client requested. If a client requests none, the grant is `read` only. Within each organization you selected, your role can lower the scopes further — a member who is not an admin gets `read` unless an admin allowed **Let regular members create powerful keys**. You can select several organizations in one authorization, and the scopes are set per organization; ask Claude to call [`list_workspaces`](/mcp/tools/agents-and-folders#list_workspaces) to see each one and its scopes. OAuth access does not expire; revoke it in [**Settings → MCP Keys**](https://app.fluxprompt.ai/dashboard-beta?settings=mcpTokens).

Claude will choose the right tool automatically based on your question. You can also ask it explicitly: *"Use `get_agent` to show me the structure of agent ID abc123"*.

## Troubleshooting

If the connection isn't working, see the [Troubleshooting](/mcp/troubleshooting) page. The most common issues are:

- Trying to use a pasted token instead of the OAuth flow (Claude Desktop only supports OAuth)
- Not completing the FluxPrompt login + consent screen
- Leaving the wrong organizations checked during consent
