## O que é uma skill

Um playbook procedural, acionado por gatilho, que o agent carrega quando a task bate com seus triggers. Mora em `.claude/skills/<name>/SKILL.md`.

## O padrão

Formato:

- Uma pasta por skill: `.claude/skills/<kebab-case-name>/`
- Obrigatório: `SKILL.md` com frontmatter.
- Sub-pastas opcionais: `templates/`, `references/`, `scripts/`.

Frontmatter:

```yaml
---
name: <kebab-case-name>
description: One sentence. Start with "Use when..." or "Triggers on...".
triggers: [list, of, keywords, or, phrases]
---
```

A fonte autoritativa é `.claude/skills/_STANDARD.md`. O linter é `scripts/skills-lint.mjs`.

## Como adicionar uma skill

1. Crie a pasta: `.claude/skills/<kebab-name>/`.
2. Escreva o `SKILL.md` com o frontmatter conforme `_STANDARD.md`.
3. Rode `node scripts/skills-lint.mjs .claude/skills`.
4. Abra um PR.

## Como mudar o padrão

Edite `.claude/skills/_STANDARD.md` **e** esta página no mesmo PR.
