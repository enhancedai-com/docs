<Note>
  This page previously described a Cursor-based `create-docs` command and a `.cursor/` folder under `docs/`. That tooling does not exist in this repository — no `.cursor/` directory has ever been part of `docs/`. Documentation authoring here is Claude Code based; see the pages below for the accurate, current workflow.
</Note>

## Where to go

- **Writing or previewing a page yourself** — [How we document](/getting-started/welcome/mintlify-quickstart) covers local preview (`mint dev`), page structure, house style, and when to update an existing page versus create a new one.
- **Delegating the writing to an agent** — [`mintlify-docs-writer`](/ai-workflows/internal-developer-workflows/agents/mintlify-docs-writer) is the Claude Code agent that asks for the target folder and content, drafts the MDX with the right components, and registers the page in `docs.json`. It is defined at `docs/.claude/agents/mintlify-docs-writer.md` and follows the `mintlify` skill at `docs/.claude/skills/mintlify.md`.

## How to invoke the agent

In Claude Code, from a workspace that includes the `docs/` folder:

```
use the mintlify-docs-writer agent to document <feature>
```

It asks for the target folder, what the documentation should cover, and any reference files before writing anything. See the [agent reference](/ai-workflows/internal-developer-workflows/agents/mintlify-docs-writer) for the full workflow, the folder-to-navigation-group mapping, and its self-verification checklist.

## Publish

Pushing to the `docs/` repository does not publish the site by itself. After your change is merged, trigger a deploy from the [Mintlify dashboard](https://dashboard.mintlify.com/enhancedai-ee242787/enhancedai-ee242787).
