## What is a skill

A procedural, trigger-driven playbook the agent loads when the task matches its triggers. Lives at `.claude/skills/<name>/SKILL.md`.

## The standard

Shape:

- One folder per skill: `.claude/skills/<kebab-case-name>/`
- Required: `SKILL.md` with frontmatter.
- Optional sub-folders: `templates/`, `references/`, `scripts/`.

Frontmatter:

```yaml
---
name: <kebab-case-name>
description: One sentence. Start with "Use when..." or "Triggers on...".
triggers: [list, of, keywords, or, phrases]
---
```

The authoritative source is `.claude/skills/_STANDARD.md`. The linter is `scripts/skills-lint.mjs`.

## How to add a skill

1. Create the folder: `.claude/skills/<kebab-name>/`.
2. Write `SKILL.md` with the frontmatter per `_STANDARD.md`.
3. Run `node scripts/skills-lint.mjs .claude/skills`.
4. Open a PR.

## How to change the standard

Edit `.claude/skills/_STANDARD.md` **and** this page in the same PR.
