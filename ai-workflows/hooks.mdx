## What is a hook

A script wired into `.claude/settings.json` under `hooks.PreToolUse` / `PostToolUse`. The script receives the tool-use event as JSON on stdin and decides allow / deny / confirm.

## Where they live

- Workspace-wide: `.claude/hooks/*.mjs` in the Workflow repo, wired in its `.claude/settings.json`.
- Per-repo: `<repo>/.claude/hooks/*.mjs` + the repo's `.claude/settings.json`, when a product repo needs its own.

## Shape

Node ESM, no npm deps:

```javascript
import { pathToFileURL } from 'node:url';

export function evaluate(event) {
  // return { decision: 'allow' | 'block' | 'confirm', reason?: string }
}

async function readStdin() {
  const chunks = [];
  for await (const c of process.stdin) chunks.push(c);
  return Buffer.concat(chunks).toString('utf8');
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) {
  const raw = await readStdin();
  const event = raw ? JSON.parse(raw) : {};
  const r = evaluate(event);
  if (r.decision === 'block') {
    process.stdout.write(JSON.stringify({ permissionDecision: 'deny', permissionDecisionReason: r.reason }));
    process.exit(2);
  }
  if (r.decision === 'confirm') {
    process.stdout.write(JSON.stringify({ permissionDecision: 'ask', permissionDecisionReason: r.reason }));
    process.exit(2);
  }
  process.exit(0);
}
```

Use `pathToFileURL(process.argv[1]).href` for the CLI gate — the naive `file://` concatenation is broken on Windows (triple-slash mismatch).

## Real examples

- [`.claude/hooks/guard-env-branches.mjs`](https://github.com/enhancedai-com/Workflow/blob/main/.claude/hooks/guard-env-branches.mjs): blocks commits on env branches, merging `develop` or `staging` into a feature branch, force pushes and pushes to `main`. It blocks by writing the reason to stderr and exiting `2`.
- [`.claude/hooks/guard-dev-loop.mjs`](https://github.com/enhancedai-com/Workflow/blob/main/.claude/hooks/guard-dev-loop.mjs): enforces the plan, approval and frozen tests on task branches.

What each one enforces: [Guardrails](/ai-workflows/claude-code-guardrails).

## Testing

Hooks are plain Node modules; test them with `node:test`, or pipe a JSON event into the script from Bash and check the exit code.
