## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Data Table Builder — Processes and structures tabular data.
FIELDS:
- tableData: The table content, filled in the editor. It is not piped in from upstream: the tableInput connection feeds nothing.
TIP: Use for organizing data into rows and columns before display or export.
```
