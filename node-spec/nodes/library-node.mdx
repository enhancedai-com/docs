title: "Space Library (Library Node)"
sidebarTitle: "Space Library"
description: "References and executes a reusable flow from the shared library. There is no generic inputs/outputs object. The referenced flow's variable inputs are fed per-node: for each of its varInputNode ids, the executor first looks for a value at textData[<varInputNodeId>] (textData is a map keyed by that id, each value a list of edge entries), and falls back to a dynamic field literally named \"<varInputNodeId>Text\" on this node's own data. Both routes are run through \"{{<nodeId>.<key>}}\" interpolation. File links (fileLinkData[<varInputNodeId>] or \"<varInputNodeId>FileLink\") reach the referenced flow only when the editor runs the node itself; a server run does not pass them. These per-node keys depend on the referenced flow's contents and are not part of this schema — do not invent or guess the id; read it from the referenced flow instead. \"input\" overrides all of them at once."
---
