## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Large Memory / RAG — Vector-based memory for large document storage and semantic retrieval.
FIELDS:
- Text input data for the knowledge base.
TIP: Use when the agent needs to reference a large body of knowledge that won't fit in a single prompt context.
```
