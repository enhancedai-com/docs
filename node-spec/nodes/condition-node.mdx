## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Decision Paths — Routes the flow based on conditions. IF/ELSE mode (true/false branches) or SWITCH mode (routes to first match).
FIELDS:
- conditions: Array of condition rules. Each has type (number/charCount/text), operator (>, <, = for number and charCount; begins, contains, ends for text), and value (what number/charCount compares against). Text conditions compare against sentimentValue. The sentiment type is not supported: it never matches, and the editor no longer offers it.
TIP: Conditions evaluate the incoming data from the previous node. SWITCH = first match wins. IF/ELSE = conditions combine with AND/OR into one true and one false branch.
```
