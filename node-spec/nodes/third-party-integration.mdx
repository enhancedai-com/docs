title: "Third Party Integration"
sidebarTitle: "Third Party Integration"
description: "Connects to a configured third-party service to pull or push data. It executes on the server (Temporal worker), so it produces output in every trigger — canvas run, API, cron, chatbot, form and batch — and downstream nodes can consume its result. HOW TO CONFIGURE ONE: pick \"provider\"; set \"mode\" to pull or push (\"mode\", not \"action\"); for a pull set \"pullObjectType\", for a push set \"pushAction\" (\"pushAction\", not \"action\"); then set the fields this schema marks as belonging to that provider and that object type or action. Fields are namespaced by provider in their descriptions, and several names are shared by more than one provider with different meanings — always read the provider list a field names before setting it. Credentials are NOT node data: the connection lives in the saved integration, selected through integrationId or connectedByUserId, and no secret, site URL or API key belongs in this node. Any field with a companion \"<field>Data\" array can be fed by an edge, and the array wins over the scalar."
---

</Info>
