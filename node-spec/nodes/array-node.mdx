## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Sequence Node — Loops over a list. Splits input into chunks and runs downstream nodes once per chunk.
FIELDS:
- options: How to split — Paragraph (default, groups sentences up to breakWords words), Sentence, or Custom Separator.
- customOperator: The separator character(s) to split on (comma, newline, pipe, etc.). Used only when options is Custom Separator.
- content: The text to split. Often piped in from upstream.
- preInput: Text prepended to each item before processing.
- postInput: Text appended to each item after the item.
TIP: content, preInput and postInput take effect only when the chunk list (processorArray) is derived from content. preInput/postInput are useful for wrapping each item in a prompt template, like "Research the following company: " as preInput.
```
