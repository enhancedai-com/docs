## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Chat Memory / Small Memory — Stores conversation history across turns in chat-style agents.
FIELDS:
- Entries accumulate at runtime. Generally configured, not manually text-edited.
TIP: This makes agents "remember" previous messages. Stores User/Assistant message pairs with timestamps.
```
