## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Image Reader — Analyzes an image using AI vision and returns text description or analysis.
FIELDS:
- prompt: What to analyze about the image. Specific prompts like "List all text visible in this image" or "Identify the products shown" produce better results than generic "describe this."
TIP: The more specific the analysis request, the more useful the output.
```
