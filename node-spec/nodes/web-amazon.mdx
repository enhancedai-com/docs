## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Amazon Search — Retrieves Amazon pages, search results, products or best sellers.
FIELDS:
- query: What to look up. With the default system "amazon-url" it holds the Amazon product URL; otherwise the search term or id the chosen system expects.
- system: Search mode — amazon-url (default), amazon-search, amazon-product, amazon-best-sellers, amazon-pricing, amazon-review, amazon-qa or amazon-seller.
TIP: Keep queries product-focused and specific.
```
