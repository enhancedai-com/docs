## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Pull Data — Reads data from Google Sheets, Docs or Slides, or from Microsoft Excel, Word or PowerPoint.
FIELDS:
- provider: google (default) or microsoft.
- selectedGoogleService: Which Google service — Google Sheets, Google Docs, or Google Slides.
- docs: The Google document ID (Google Docs only).
TIP: Use the document ID from the Google URL. Service selection determines how the data is parsed.
```
