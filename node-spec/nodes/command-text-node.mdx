## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
AI Text Generator — Calls an LLM to generate text. The workhorse node for any AI-driven task.
FIELDS:
- persona: WHO the AI is. Role identity, expertise, personality, communication style. Write in second person ("You are..."). Do NOT put task instructions or output format rules here — those go in instruction.
- prompt: WHAT to do. The main task or question. Concise, starts with a verb. If the node receives dynamic data from upstream, reference it naturally ("Analyze the following…"). Runs every execution.
- instruction: HOW to respond. Output format, length limits, what to include/exclude, edge case handling, quality criteria. This is where structure templates and numbered rules go.
- content: Static reference material or background context. Often empty when dynamic data is piped in via content connector.
TIP: Persona = who you are. Instruction = rules to follow. Prompt = what to do right now. Content = what to reference. Keep them separate.
```
