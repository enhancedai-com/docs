## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Audio Reader — Transcribes audio to text using speech recognition, or reads a YouTube video's transcript.
FIELDS:
- inputPreview: URL of the audio file to transcribe. Often piped in from upstream.
- youtubeUrl: YouTube video URL, used when type is ytTranscript.
TIP: Output is the transcribed text from the audio input.
```
