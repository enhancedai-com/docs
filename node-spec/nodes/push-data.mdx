## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Push Data — Writes data to Google (Sheets, Docs, Slides, Raw Files) or Microsoft (Excel, Word, PowerPoint, Raw Files).
FIELDS:
- selectedFolderDoc: Target Google Drive folder for a new Google Doc or an uploaded file.
- newDocumentName: Name for a newly created document.
- name: Title of the new Google Sheets worksheet (when sheets is "new").
TIP: Creates or updates documents in the specified folder.
```
