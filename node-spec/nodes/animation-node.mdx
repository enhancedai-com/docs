## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Video / Animation Generator — Generates video or animation from a text prompt.
FIELDS:
- prompt: Visual scene description including subject, motion, camera movement, style, lighting. Describe what HAPPENS over time.
TIP: Include motion and change — video prompts need action, not just static scenes.
```
