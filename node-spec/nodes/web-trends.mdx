## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Google Trends — Retrieves trend data for search terms.
FIELDS:
- query: The search term to get trends for.
- type: Request kind — "trends" (uses query and data_type) or "trends-now" (current trending searches).
- data_type: Data to retrieve for "trends" — TIMESERIES, GEO_MAP, GEO_MAP_0, RELATED_TOPICS or RELATED_QUERIES.
TIP: Use for market research, content planning, or competitive analysis.
```
