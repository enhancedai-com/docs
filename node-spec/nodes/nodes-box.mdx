## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Object Viewer — Reads and writes a specific FluxPrompt object's data.
FIELDS:
- selectedId: The object ID to read and write.
TIP: Useful for displaying stored object contents or updating its fields (append, replace or clear per field).
```
