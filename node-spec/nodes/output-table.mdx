## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Table Output — Displays data as a formatted table in the output.
FIELDS:
- tableData: The rows to display. Not piped in via connector; filled in the editor or by a Table Processor run.
TIP: Works best paired with a Table Processor, which writes its selected columns here.
```
