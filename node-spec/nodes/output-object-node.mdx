## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Data Output — Sends data out of the agent as chat response, email, or API response.
FIELDS:
- emails: Recipient email addresses (when email output is enabled).
- subject: Email subject line.
TIP: Can function as chat response, email sender, or API endpoint. Enable email in node settings.
```
