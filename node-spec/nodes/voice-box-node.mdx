A voice id that the provider does not know is refused."

## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Voice Generator — Converts text to speech using ElevenLabs or other providers.
FIELDS:
- text: The text to speak. Often piped in from upstream.
- voiceId: ElevenLabs voice ID.
- stability / similarity_boost / style: Voice tuning parameters (0 to 1).
TIP: Spoken text should be conversational, not formal written style. Short sentences work better for natural speech.
```
