## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Text Box — Holds static text that feeds into other nodes via content connectors. Content-only node with NO process connections.
FIELDS:
- text: The exact text content. Could be instructions, reference data, templates, examples, or any static content another node needs.
TIP: Often used to hold system prompts, instruction sets, or reference material that feeds into an ATG's instruction or content field. Whatever you write here is passed verbatim to the connected node.
```
