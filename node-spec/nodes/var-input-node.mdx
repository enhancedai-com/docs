## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Data Input — Receives user input or webhook data at runtime. Entry point for interactive or API-triggered agents.
FIELDS:
- Configured via settings. Label describes what input is expected.
TIP: For webhook agents, this receives the incoming API payload. For chat agents, this is where the user types.
```
