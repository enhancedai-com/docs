## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Display Box — Renders final output for the user to see. Typically an end point in the flow.
FIELDS:
- Receives content via connector. Label can be customized.
TIP: If the user wants formatted output, suggest adding an ATG before the Display Box to convert content to HTML.
```
