## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
SEC API — Queries SEC EDGAR APIs for company filings and financial data.
FIELDS:
- model: Which SEC API is called (e.g. sec-query, sec-full-text-search, sec-ticker). It decides what query holds.
- query: The value the chosen model looks up. There is no ticker field: for a ticker lookup, set model to "sec-ticker" and put the ticker in query.
TIP: Use for financial research, filing lookups, and company financial data.
```
