## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Rich Text Box — Same as Text Box but supports HTML formatting. Content-only node with NO process connections.
FIELDS:
- text: HTML-formatted text content. Can include tags for bold, lists, headers, etc.
TIP: Use when downstream nodes need formatted content, especially if feeding into a Display Box or email output.
```
