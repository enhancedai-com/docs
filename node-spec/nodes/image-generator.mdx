## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Image Generator — Generates images from text prompts using AI.
FIELDS:
- prompt: Visual description of the desired image. Include subject, style, mood, composition, lighting, color palette. More detail = better results.
TIP: Describe what you SEE, not what you MEAN. "A cozy kitchen with warm golden lighting, rustic wooden countertops, copper pots hanging from ceiling, photorealistic" beats "a nice kitchen."
```
