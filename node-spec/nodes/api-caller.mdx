## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
API Caller — Makes HTTP requests to external APIs (GET, POST, etc.).
FIELDS:
- url: The API endpoint URL. Can include dynamic path segments.
TIP: Headers, method, body, and auth are configured in node settings. URL can be built dynamically from upstream data.
```
