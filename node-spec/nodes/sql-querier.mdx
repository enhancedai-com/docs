## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
SQL Database — Executes queries against a connected MySQL, PostgreSQL, SQL Server, MongoDB or Firebase database.
FIELDS:
- dbms: Required — MySQL, PostgreSQL, MongoDB, SqlServer or Firebase. It decides which fields below apply.
- query: The SQL query to execute (MySQL/PostgreSQL/SqlServer). Can include dynamic values from upstream.
- host / port / database / username / password: Connection details for MySQL/PostgreSQL/SqlServer.
- uri: MongoDB connection URI, required for MongoDB.
TIP: Write production-safe SQL. Be careful about injection if upstream data comes from user input. Test queries with LIMIT before running on full tables.
```
