## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Functions — Performs mathematical or string operations on variables - in an excel-like formula.
FIELDS:
- variables: Named variables (varOne, varTwo, etc.) with values. Can receive dynamic input from upstream.
- formula: The calculation or operation using those variable name - using excel-like formulas, or more specifically: https://formulajs.info/functions/
TIP: Supports standard math operations and Excel string functions like LEN and CONCATENATE. Join text with "&", not "+".
```
