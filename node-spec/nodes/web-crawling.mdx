## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Web Scraper — Scrapes a URL and returns its page content as text.
FIELDS:
- url: The target URL to scrape. Can receive dynamic URLs from upstream nodes.
TIP: Works best on content-heavy pages. Some sites block scraping.
```
