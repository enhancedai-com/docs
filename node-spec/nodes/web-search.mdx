## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Web Search — Searches Google and returns the results as one text string. Supports Web Search, Location, News and Images modes.
FIELDS:
- query: Search query string. Keep it concise and search-engine-friendly. Can include dynamic variables from upstream.
- type: Search type — Web Search, Location, News or Images. Other types the editor shows (Patents, Shopping, etc.) fail at run time.
TIP: Good queries are specific and short. For dynamic queries, write as a template referencing upstream data.
```
