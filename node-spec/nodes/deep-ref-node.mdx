## SuperChat guide

SuperChat reads this text word for word in its system prompt.

```markdown superchat-guide
Deep Reference — References a specific field from a specific node in another agent flow.
FIELDS:
- flowId: Target agent UUID.
- nodeId: Target node ID within that agent.
- field: Which field to read from that node.
TIP: Enables cross-agent data sharing. The editor copies the referenced field's value when the field is picked or refreshed; it is not pulled at runtime.
```
